PanelSafe: Small Object Detection & Automated Audits

Root-causing a silent label-ordering bug, correcting detections with an HMM sequence decoder, and deploying containerized GPU inference.

Role ML Engineer, DevOps & Lead Architect
Stack Python, YOLOv8, PyTorch, OpenCV, Docker
Timeline July 2025 - July 2026 (Commercial Launch)

1. The Engineering Challenge

During electrical audits, electricians manually verify and document the states of breakers inside electrical protection boards. This is tedious, error-prone, and poses safety risks. PanelSafe replaces this workflow with image-based recognition. However, breaker boards present a dense matrix of very small, repeating switches. Standard object detection algorithms struggle to localize tiny, identical components on high-resolution parent images.

Domain Generalization Gap

While models performed exceptionally well on clean test datasets, real-world deployment introduced "domain drift." In the field, panels are often unboxed (exposing messy wires), switches are dusty, and panel markings are handwritten. To achieve commercial robustness, the data pipeline had to adapt.

2. The 92% That Meant Nothing

The model scored 92% on real-world validation images and was visibly wrong in the field — confidently calling differentials MCBs and vice versa. The intuitive reading was a resolution problem: tiny, near-identical objects on a high-resolution image. So the first fix attempted was slicing-aided inference, tiling the panel into overlapping windows and merging with NMS.

It didn't help, because the premise was wrong. The real cause was that the annotation tool wrote its class indices from a classes.txt whose ordering disagreed with the data.yaml the training run read. Every hand-labelled real image was permuted — not a simple two-class swap, but a full six-class rotation. The model had faithfully learned the permutation.

label_remap.py
# What the annotation tool wrote vs. what training actually read
CLASSES_TXT = ["RCD", "MCB", "MAINBREAKER", "OVERSURGE", "OTHER", "RCD_SI"]
DATA_YAML   = ["MCB", "RCD", "RCD_SI", "MAINBREAKER", "OVERSURGE", "OTHER"]

# Every real annotation had to be rewritten through this map
REMAP = {written: DATA_YAML.index(name)
         for written, name in enumerate(CLASSES_TXT)}
# -> {0: 1, 1: 0, 2: 3, 3: 4, 4: 5, 5: 2}

# Synthetic labels were generated programmatically against data.yaml,
# so they were correct all along -- which is exactly why the bug hid:
# the corrupted subset was small enough to look like ordinary noise.

Scored against corrected labels, that same 92% became roughly 6%. The metric had never measured accuracy; it measured agreement with a broken ground truth.

The Ablation That Removed My Own Work

With the labels fixed, the slicing optimisation was re-run as a controlled ablation rather than assumed to help. It measurably reduced accuracy, so it was cut from the production pipeline. The dependency is still listed in requirements.txt, annotated with why it is deliberately unused — so nobody, including a future me, re-adds it on intuition without re-running the experiment.

3. Synthetic Data Engineering

With only 80+ high-resolution physical images, training a deep neural network was susceptible to overfitting. We built a custom synthetic pipeline that crops individual breakers, generates alpha masks, and pastes them in random configurations on various electrical panel backgrounds, expanding the training library by 10x.

4. DevOps & Containerized Deployment

To demonstrate production-grade reliability, the PanelSafe inference API is containerized using Docker and deployed as a microservice. A local CI/CD pipeline runs unit tests, verifies linting compliance, and pushes the built container.

Dockerfile
FROM python:3.10-slim

WORKDIR /app

# Install system utilities for OpenCV
RUN apt-get update && apt-get install -y \
    libgl1-mesa-glx \
    libglib2.0-0 \
    && rm -rf /var/lib/apt/lists/*

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY src/ ./src/
COPY models/ ./models/

EXPOSE 8000

CMD ["uvicorn", "src.main:app", "--host", "0.0.0.0", "--port", "8000"]
.github/workflows/deploy.yml
name: Build and Deploy Inference Service

on:
  push:
    branches: [ main ]

jobs:
  lint-and-test:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v3

      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.10'

      - name: Install Linting & Testing Libraries
        run: |
          pip install flake8 pytest
          pip install -r requirements.txt

      - name: Lint Python Code
        run: flake8 src/

      - name: Run Unit Tests
        run: pytest tests/

  build-container:
    needs: lint-and-test
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v3

      - name: Build Docker Image
        run: docker build -t panelsafe-inference:latest .
