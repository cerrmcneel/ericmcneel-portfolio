electromarjal.com: High-End Solar & Electrical Platform

Architecting a multi-lingual, high-performance customer conversion portal for a premium electrical services provider in Spain.

Role Full Stack Developer & Owner
Stack HTML5, CSS3, JavaScript (Vanilla), JSON-LD, Docker
Target Audience Spanish Locals, English Expats, French Retirees

1. Business Context & Engineering Challenge

To support the transition from Sole Proprietorship (Autónomo) to a Limited Company (S.L.) structure, Marjal Instalaciones Eléctricas required a digital presence matching its high-end physical services. The target region (the Maestrat comarca: Peñíscola, Benicarló, Vinaròs) is uniquely multi-demographic, requiring seamless Spanish (ES), English (EN), and French (FR) availability to convert residential owners, foreign property investors, and French-speaking retirees.

Strict REBT & Local Regulatory Context

Electrical safety documentation in Spain requires strict adherence to REBT (Reglamento Electrotécnico para Baja Tensión) regulations. Highlighting official certifications (such as Boletines CIE) with clear fixed pricing structures was crucial to building instant consumer trust online.

2. Multi-Lingual Architecture & Local SEO

To minimize hosting overhead and maximize page-speed scores for mobile-first users in low-connectivity areas, we selected a clean semantic framework over bloated client-side JavaScript frameworks. We structured multi-lingual pages using static subdirectory routing (e.g. /en/index.html) to ensure clean crawler indexes.

To capture local Google Search visibility, we embedded custom Schema.org metadata using JSON-LD. This explicitly defines the physical address, geo-coordinates, operating hours, and area served, telling search engines precisely when and where the services operate.

3. Interactive Solar Savings Estimator Wizard

To capture premium solar leads, we built a step-by-step wizard. Users slide their average monthly electricity bill, select their roofing type, and receive a real-time technical estimate. Instead of forcing database interactions, the calculator performs instant client-side math and serializes user details into formatted emails.

calculator_logic.js
// Solar Calculation Coefficients based on average solar irradiance in Castellón
const AVERAGE_PEAK_SUN_HOURS = 4.6; // hours/day in East Coast Spain
const SYSTEM_EFFICIENCY_LOSS = 0.82; // 18% standard system loss

function calculateSolarOutput(monthlyBill) {
    // 1. Est. Monthly consumption in kWh (assuming average price of 0.20€/kWh)
    const monthlyKwh = monthlyBill / 0.20;
    const dailyKwhTarget = (monthlyKwh / 30) * 0.70; // Target covering 70% daytime load
    
    // 2. Required system size in kWp
    const requiredKwp = dailyKwhTarget / (AVERAGE_PEAK_SUN_HOURS * SYSTEM_EFFICIENCY_LOSS);
    
    // 3. Number of standard panels (assuming 450Wp per panel)
    const numPanels = Math.ceil((requiredKwp * 1000) / 450);
    
    // 4. Payback period estimate (assuming standard installation costs)
    const estimatedCost = numPanels * 750 + 1500; // 750€ per panel + inverter/labor setup
    const annualSavings = (monthlyKwh * 12 * 0.70) * 0.20; // 70% bill reduction
    const paybackYears = (estimatedCost / annualSavings).toFixed(1);
    
    return {
        kWp: requiredKwp.toFixed(2),
        panels: numPanels,
        cost: estimatedCost,
        payback: paybackYears
    };
}

4. Containerized Web Hosting

For hosting robustness, the site, assets, and calculator utilities are containerized using **Docker** and proxy-routed via an Nginx service. This setup is managed through docker-compose on the local platform, matching the infrastructure configuration used in PanelSafe's deployment.
